# Mentora – működő prototípus

A prototípus a teljes tanár–diák tanulási folyamatot demonstrálja: tartalomkészítés, megosztás, személyre szabott gyakorlás, eredmény és visszajelzés.

## Fő funkciók

- JWT-alapú regisztráció és bejelentkezés tanár/diák szerepkörrel
- kvíz CRUD, kérdésszerkesztés és szerveroldali pontozás
- helyi Ollama-alapú kérdésgenerálás szövegből, PDF-ből és DOCX-ből
- tanulónkénti adaptív kérdéskiválasztás
- Flashcards csomagok ütemezett ismétléssel
- témák, kódos/linkes megosztás és tanár–diák visszajelzés
- XP, szintek, badge-ek, streak, napi küldetések és heti célok
- előre letöltött kvízek és Flashcards csomagok korlátozott offline használata
