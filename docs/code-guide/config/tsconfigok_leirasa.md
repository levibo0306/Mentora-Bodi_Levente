# TypeScript konfigurációk leírása

A frontend és backend `tsconfig.json` fájlok mondják meg a TypeScript fordítónak a nyelvi célt, modulrendszert, strictséget, bevont fájlokat és JSX kezelést. A frontend böngészős/Vite környezetre és React JSX-re, a backend Node környezetre fordít. Ezek hibája buildidőben derül ki, mielőtt hibás típusú adat a futó alkalmazásba kerülne.
