# Frontend `package.json` leírása

A React/Vite alkalmazás csomagdefiníciója. A `dev` Vite szervert, a `build` production bundle-t, a `test` Vitest unit teszteket, a `test:e2e` Playwright böngészőteszteket indítja. Runtime függőségei React, React DOM és React Router; a többi fejlesztési/build eszköz.
