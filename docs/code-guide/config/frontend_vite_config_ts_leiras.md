# `frontend/vite.config.ts` leírása

A Vite build- és fejlesztői szerver beállítása. Bekapcsolja a React plugint, és meghatározza a helyi fejlesztéshez szükséges viselkedést. A Vite olvassa a `VITE_` prefixű környezeti változókat, köztük az API alap URL-jét. Production buildnél ez készíti a `dist` mappát.
