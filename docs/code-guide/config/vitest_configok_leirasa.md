# Vitest konfigurációk leírása

A frontend és backend `vitest.config.ts` fájlok a unit/integrációs tesztek környezetét, fájlmintáit, timeoutjait, coverage beállítását és riportereit adják meg. A JUnit és coverage riportok a dokumentált sprint-riport mappába kerülhetnek. Nem alkalmazási logikát tartalmaznak, hanem annak ellenőrzési keretét.
