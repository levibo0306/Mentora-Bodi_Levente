# Backend `package.json` leírása

Az Express szerver csomagdefiníciója. Scriptjei a fejlesztői/production indítást, TypeScript buildet, migrációt, seedelést és backend teszteket vezérlik. Függőségei többek között Express, PostgreSQL kliens, JWT, bcrypt, Zod, multer, dokumentumfeldolgozók és Sentry.
