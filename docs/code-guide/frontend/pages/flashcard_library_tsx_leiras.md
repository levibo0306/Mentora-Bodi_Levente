# `pages/FlashcardLibrary.tsx` leírása

Vékony oldalburkoló a teljes tanulókártya-munkaterület körül. A `PageLayout` egységes oldalcímet és szélességet ad, a tényleges létrehozási, importálási, gyakorlási és megosztási logikát a `Flashcards` komponens tartalmazza. Azért létezik külön, hogy a `/flashcards` route tiszta, önálló oldalként használhassa ugyanazt a modult.
