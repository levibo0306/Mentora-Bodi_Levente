# `ui/PageLayout.tsx` leírása

Egységes külső keret a dashboardon kívüli alkalmazásoldalakhoz. A `title`, opcionális `subtitle`, `children` és `width` propokat fogadja. A `wide` vagy `medium` szélesség CSS osztályt választ. Nem végez adatlekérést vagy navigációt; kizárólag következetes címsort, margót és tartalomszélességet biztosít.
