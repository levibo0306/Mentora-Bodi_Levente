# `ui/SharedWithMe.tsx` leírása

A diákkal megosztott kvízek listája. A normál kvízadat mellett megjeleníti a készítőt, megosztót, dátumot és továbbosztási engedélyt. Indítható, offline menthető, és ha `allow_reshare` igaz, továbbosztható. A lista a `/api/quizzes/shared-with-me` végpontról érkezik, az offline logika megegyezik a saját kvízekével.
